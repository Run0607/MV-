# ダダダダ天使 MV（黒キャラ版）

本家MVの構成・テンポ（BPM180）をなぞって、黒キャラとモブ4人に置き換えたMV。
キャラは**提供イラストを切り抜いたもの**をそのまま使い、拍に合わせて
体のしなり（上ほど大きく揺れる）・頭の揺れ・着地の潰れ・羽ばたきで動かしている。

## 見る
```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
- 「♪ 音源を選ぶ」で自分の歌（wav/mp3）を読み込むと音に同期して再生
- 音がズレる時は「音ズレ補正(秒)」で調整（プラス＝映像を早める）
- スペース：再生/停止、←→：2秒移動、`?t=62` で途中から

## mp4 に書き出す
```bash
npm i && npx playwright install chromium   # 初回のみ
node render/render.js --audio 歌.wav --out mv.mp4 --offset 0
```
ffmpeg が必要。1280x720 / 24fps。

## 編集するところ
| ファイル | 中身 |
|---|---|
| `src/lyrics.js` | **歌詞・セリフ・クレジット**（`〈…〉` が仮置き）、モブの合いの手 |
| `src/timeline.js` | ショット構成、ポーズ/表情の切り替えタイミング（`KK`） |
| `src/kuro.js` | キャラの動かし方（揺れ・羽・アップの切り出し） |
| `assets/chars/` | 切り抜き済みキャラ画像（差し替え可） |
| `assets/kuro_real.png` | 頭身高めパート用のリアル絵 |

### キャラ画像
